# Campfire MVP Roadmap

## Главные принципы проекта
### Campfire — не виртуальный стол.
Он сопровождает живую игру в Discord, а не заменяет её.

### Одна активная сцена.
В центре всегда только одно основное состояние (повествование, бой, торговля, загадка и т.д.).

### Всё — через события.
Любое действие игрока проходит через единую систему событий. ГМ принимает решения, система считает механику. После подтверждения все изменения происходят автоматически.
Минимум кликов, и игрок, и ГМ должны выполнять частые действия максимально быстро.
Интерфейс должен быть атмосферным, не таблицы и формы, а карточки, сцены и понятные визуальные элементы.

## 🧪 Вертикальный срез (Vertical Slice)

1. ГМ создаёт кампанию.
2. Игрок подключается.
3. Открывается NarrationScene.
4. Игрок открывает инвентарь.
5. Использует предмет.
6. ГМ подтверждает действие.
7. Система автоматически применяет эффект.
8. ГМ запускает BattleScene.
9. Игрок делает бросок по запросу.
10. Бой заканчивается.
11. ГМ выдаёт предмет и квест.
12. Кампания сохраняется.
